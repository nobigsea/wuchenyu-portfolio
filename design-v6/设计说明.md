# 吴晨渝作品集 · 拙趣档案袋版

入口：index.html。保留 design-v3 / v4 / v5 和独立排版编辑器，本版在 design-v6。

## 本轮设计
沿用 Taste Skill 的 page-is-the-object（seed 1922147375），按用户明确的新参考覆盖原深色配色，不重新抽取随机风格。

“把吴晨渝从评论与现场观察中完成的内容，装进可以展开的个人档案袋。”

图片配色转为：纸白 #fdfcf8、笔触蓝 #315d91、浅黄 #eddfa0、柠檬黄 #eeeca2、灰蓝 #ceddeb、粉橘 #f2c9bf、浅绿 #d6e9e1、浅紫 #ded6ed。主要文字统一蓝色，色块按内容分区使用。中文标题采用本机楷体，正文为系统黑体，无远程字体依赖。

首页档案袋由可编辑的 HTML/CSS 和一条蓝色绳结 SVG 构成；点击展开四个真实案例入口，支持键盘、Esc 收起和减少动态效果。视频仅用于参考档案袋的展开结构，没有作为本人作品上传或复制其中的文字、标识、贴纸。

保留左侧分区导航、右侧阅读进度、滚动切换案例、9:16 作品库、筛选、完整历史截图弹窗、四个案例详情页和邮件联系。项目成绩及个人责任范围沿用已经确认的内容。

# 当前版本更新：六项结构调整

本节覆盖上文较早的页面结构说明。

1. 首页删除可见大标题与职业说明，将“吴晨渝的”“2026作品集”放在放大的三维档案袋两侧。手机端移到模型上方两端，避免遮挡模型。
2. 删除独立代表成果版块及对应导航；各案例中的真实成果仍随项目展示。
3. 删除独立关于我版块及对应导航；自我介绍保留在档案袋内。
4. 精选案例采用四个切角标签页、顶部标题与职责、下方大幅作品和补充图的档案界面。原生页面滚动驱动切换，标签与箭头均可操作。
5. 四个详情页采用左侧固定项目名称、职责、亮点，右侧连续展示作品及文字的分屏结构。手机为先摘要、后作品的单列顺序。页面从同一份网站素材配置读取视频，仍保留历史数据截图入口。
6. 入场标签按 sessionStorage 在当前标签页的第一次打开时显示，从详情返回或刷新不重复。离开页面时清除正在显示的标签，避免浏览器返回缓存恢复旧动画。

三维对象使用本地 Three.js 0.180.0（MIT）和真实网格、折叠轴、纸张贴图、灯光与阴影。支持拖动和键盘连续旋转、回到正面、翻面抽出、折页展开、逆向收回。阅读状态使用可访问的 HTML 自我介绍；也可返回三维内页继续查看。

标题字体更新为 Noto Serif SC 黑体重（SIL Open Font License；Google Fonts 官方源）。完整字体先下载到本机，再本地裁剪压缩成116KB字库；未向字体服务提交作品集文字。完整原字体作为新增字符的回退保存。

最终验证：四个详情页的1440/768/390尺寸均无横向溢出、三行标题；手机图片无缺失。实际浏览器验证了首页至详情再返回不重复入场标签、切换档案、三维完整360度旋转、抽出自我介绍。源码检查0 FAIL/0 WARN。独立 inspect.mjs/scenes.mjs 未运行，采用当前浏览器工具核验。
